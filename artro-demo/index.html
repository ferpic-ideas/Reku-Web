EN ESTA SESIÓN DE PRUEBA

Mis turnos

Sólo se muestran los turnos creados en esta sesión. Antes de reiniciar la demo, conservá los enlaces de confirmación para volver a ingresar. Reiniciar no cancela los turnos.

Para el equipo técnico Ver llamadas a la API

El navegador llama a /test/api. Un backend intermedio mantiene una sesión de prueba anónima y llama a /api/partners/v1 con la credencial privada de Artro. Las operaciones de escritura usan Idempotency-Key.

La demo es de acceso libre; la cuenta registrada, el email validado y el pago se simulan. En una integración final, el backend debe obtener la identidad del usuario autenticado y validar el pago antes de confirmar.
